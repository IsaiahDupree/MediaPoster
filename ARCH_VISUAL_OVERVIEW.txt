 PIPELINE EXECUTION WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Client Request
        └─ POST /api/orchestrator/pipeline/start
           {theme: "AI automation", num_parts: 3, ...}
           ⏱ ~100ms

Step 2: Pipeline Initialization
        └─ Create PipelineConfig
           └─ Save to database
              └─ Initialize pipeline steps
                 └─ Emit ORCHESTRATOR_PIPELINE_STARTED
                    ⏱ Instant

Step 3: Sora Video Generation (ARCH-002)
        └─ Emit SORA_BATCH_REQUESTED
           └─ Generate 3-part AI prompts
              └─ Queue concurrent Sora jobs (limit: 3)
                 └─ Download completed videos
                    └─ Remove watermarks
                       └─ Stitch videos together
                          └─ Analyze content (titles, hashtags, hooks)
                             └─ Emit SORA_BATCH_COMPLETED {analysis}
                                ⏱ 2-5 minutes

Step 4: Content Analysis & Metadata (ARCH-003)
        └─ Receive SORA_BATCH_COMPLETED
           └─ Extract platform metadata
              ├─ TikTok: "Hook-driven title"
              ├─ Instagram: "Engagement-focused"
              ├─ YouTube: "SEO-optimized"
              └─ Others: Auto-filled metadata
                 └─ For each platform: Emit PUBLISH_REQUESTED
                    ⏱ Instant

Step 5: Multi-Platform Publishing
        └─ Receive PUBLISH_REQUESTED × 22 platforms
           └─ Format per platform specifications
              └─ Post to platform APIs (parallel)
                 └─ Poll for confirmation
                    └─ Emit PUBLISH_COMPLETED per platform
                       ⏱ 2-5 minutes

Step 6: Twitter Campaign Scheduling (ARCH-004)
        └─ When all platforms published
           └─ If schedule_tweets == true
              └─ Emit twitter.campaign.schedule_requested
                 └─ Create 12 tweets (configurable)
                    └─ Schedule at 2-hour intervals
                       └─ Emit TWITTER_CAMPAIGN_SCHEDULED
                          ⏱ 30 seconds

Step 7: Offer Traffic Tracking (ARCH-005)
        └─ Generate UTM-tracked links
           └─ utm_source={platform}
              └─ utm_campaign=pipeline-{id}
                 └─ Provide tracking URLs to tweets
                    ⏱ Instant

Step 8: Analytics Feedback (ARCH-006)
        └─ Monitor metrics as they arrive
           └─ AI analyzes:
              ├─ Theme effectiveness
              ├─ Platform performance
              ├─ Audience response
              └─ Conversion efficiency
                 └─ Generate recommendations for next pipeline
                    ⏱ 5-10 minutes

Step 9: Pipeline Completion
        └─ Mark all steps as completed
           └─ Update database status
              └─ Emit ORCHESTRATOR_PIPELINE_COMPLETED
                 └─ Return results to client

TOTAL TIME: 10-15 minutes
PLATFORMS PUBLISHED: 22 accounts
TWEETS SCHEDULED: 12 (2-hour intervals)
METRICS TRACKED: Yes (clicks, conversions)
