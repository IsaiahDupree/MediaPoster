## Features to Build

### F1 — Add JTBD Fields to ICP
Jobs-To-Be-Done is the highest-ROI hook-improvement available.
Add to `ICP` dataclass:
- `functional_jobs: List[str]` — What they're trying to accomplish
- `emotional_jobs: List[str]` — How they want to feel
- `social_jobs: List[str]` — How they want to be perceived

Update `content_generation_pipeline.py` `_build_prompt()` to include JTBD jobs in the prompt.
Add DB migration for `icp_jtbd` table or JSONB column on existing ICP table.
Add `PUT /api/icp/{icp_id}/jtbd` to update JTBD for an ICP.

### F2 — Sophistication Level on ICP
Add `sophistication_level: int` (1–5) to `ICP` based on Schwartz's market sophistication model.
- Level 1: Bold direct claim works
- Level 3: Need mechanism + proof
- Level 5: Pure story, zero claims

Wire into content generation: higher sophistication → lower temperature, more nuanced prompts.
Add `GET /api/icp/{icp_id}/sophistication-tips` returning prompt guidance for the level.

### F3 — Psychographic Segment Field
Add `psychographic_segment: str` to `ICP` with values: `achiever`, `experiencer`, `striver`, `thinker`, `maker`, `believer`.
Each segment maps to expanded `TRIBE_PATTERNS` in `FATEScorer`.
Add segment-specific patterns to `score_tribe()` — e.g., `achiever` patterns include "results", "outcome", "metric".
Add `POST /api/icp/classify-psychographic` that uses GPT-4o to classify an ICP description into a segment.

### F4 — Awareness Distribution Auto-Update
`ICP.awareness_distribution` tracks what % of your audience is at each awareness level.
Currently not populated. Build `AwarenessDistributionTracker`:
1. After every piece of content is published, store its awareness level
2. After 24h, fetch engagement data
3. Update `awareness_distribution` weighted by engagement (more engaged = larger share)
Expose via `GET /api/icp/{icp_id}/awareness-distribution`.

### F5 — ICP → Channel Routing Validation
`channel_router.py` maps ICP + awareness → recommended platforms.
Add unit tests covering all combinations.
Add `POST /api/icp/route` accepting `{ icp_id, content_text }` and returning
`{ recommended_platforms: [], awareness_level: int, reasoning: str }`.
Reasoning generated by GPT-4o using ICP + FATE scores as context.

## Success Criteria
- JTBD fields persisted in DB and used in every content generation prompt
- Sophistication level influences prompt temperature measurably
- Psychographic classifier uses real GPT-4o call
- Awareness distribution updates automatically after each published piece
- Channel routing endpoint returns reasoning from real AI call
