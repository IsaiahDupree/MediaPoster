## What that is “in terms of NLP”

People use **“NLP”** two different ways, so here’s both:

### 1) NLP = *Neuro-Linguistic Programming* (persuasion/coaching)

In *that* sense, FATE is basically a **stacked persuasion frame**—you’re not relying on “clever words,” you’re building the conditions that make words land (attention, credibility, identity, emotion). ([PodScripts][5])

Practical translation into script tactics:

* **Focus (Hook)**

  * Pattern interrupt + curiosity gap + concrete stakes (“If you’re doing X, this is why it keeps failing…”)
* **Authority**

  * Specific proof (numbers, receipts, constraints), confident naming, clear mechanism (“Here’s the mechanism…”)
* **Tribe**

  * Identity labels + “people like us” language + shared enemy/friction (“Most founders get lied to by…”)
* **Emotion**

  * Story beats, contrast, loss aversion, relief/hope, vivid sensory language

Important caveat: **Neuro-Linguistic Programming as a formal therapeutic/coaching system has weak evidence support** in scientific reviews (so treat it like a *toolbox of rhetorical techniques*, not a proven science). ([PMC][6])

### 2) NLP = *Natural Language Processing* (AI/ML)

If you meant **computational NLP**, then FATE becomes a **labeling/scoring model** for scripts:

* Detect **Focus** via novelty cues, specificity, surprise words, question hooks
* Detect **Authority** via credentials, numbers, citations, “how it works” mechanism language
* Detect **Tribe** via in-group/out-group terms (“we/they”, identity labels)
* Detect **Emotion** via sentiment/arousal words, emotional verbs, vivid imagery

## A simple “FATE script skeleton” you can reuse

1. **Focus:** 1–2 line hook (specific, slightly disruptive)
2. **Authority:** 1 proof line + 1 mechanism line
3. **Tribe:** “If you’re [identity], you’ve seen [shared frustration]…”
4. **Emotion:** quick story/contrast + clear payoff
5. **Close:** single next step CTA

Eugene Schwartz’s **5 Stages (Levels) of Awareness** (from *Breakthrough Advertising*) describe **how much your prospect knows** about (1) their problem, (2) solution categories, (3) your product, and (4) why your product is *the* choice. ([ActiveCampaign][1])

The big rule: **each stage comes with different “questions in their head,” so your script has to answer *those* questions**—otherwise you waste spend and attention (e.g., “product-aware” messaging shown to “problem-aware” people). ([Breakthrough Advertising][2])

Below is a detailed, “what they’re thinking → what your script must do” breakdown.

---

## 1) Unaware

**Mindset:** They **don’t realize they have a problem** (or don’t frame it as a problem worth fixing). Often they’re just living life; your category isn’t on their radar. ([ActiveCampaign][1])

**What they’re thinking (implicit):**

* “I’m fine.”
* “That’s not me.”
* “I’m not shopping for anything.”

**Your job in the script:**

* Create *awareness* by **surfacing a symptom**, reframing a “normal annoyance” as a solvable issue, or telling a story that makes them recognize themselves.
* This is where you earn attention with **pattern interrupts, curiosity, and relatable scenes** (more emotion/story, less product).

**Best angles:**

* “You might be doing X without realizing it’s costing you Y.”
* “Most people think Z is normal—until they see this.”

**Best CTA:** super low-friction: watch, read, self-assess, quiz, “see if this applies to you.”

---

## 2) Problem-Aware (aka Pain-Aware)

**Mindset:** They **feel the pain** and can name it somewhat, but they’re not clear on solutions (or they don’t connect the solution to *your* category yet). ([ActiveCampaign][1])

Copyhackers’ summary of this stage: they know they have a problem, but may not fully understand it and are unfamiliar with solutions. ([MessageExcellence][3])
Schwartz’s famous framing here: “**not a desire—but a need**.” ([Martin Roth][4])

**What they’re thinking:**

* “This is annoying / stressful.”
* “Why is this happening?”
* “I need relief, but I don’t know the right approach.”

**Your job in the script:**

* **Mirror the pain** (empathy + specificity).
* Clarify the **real cause** (or the hidden cost).
* Introduce that **solutions exist** and preview a credible path forward—*without* leading with your product too hard.

**Best angles:**

* “If you’ve tried X and it still happens, here’s why…”
* “The problem isn’t your effort—it’s the approach.”

**Best CTA:** guide-level CTAs: checklist, mini training, “here are the options,” simple lead magnet.

---

## 3) Solution-Aware

**Mindset:** They know what kind of outcome they want and **they know solutions exist**, but they don’t know your product (or don’t know which solution type is best). ([ActiveCampaign][1])

Schwartz (as commonly quoted) describes it like: they want what the product *does*, but don’t yet know there’s a product (your product) that will do it for them. ([GrowthMarketer][5])

**What they’re thinking:**

* “What’s the best way to solve this?”
* “Should I use approach A or B?”
* “Which method actually works for someone like me?”

**Your job in the script:**

* **Educate + categorize**: explain the main solution approaches and their tradeoffs.
* Position your “mechanism” as the **most sensible path** (this is where authority + clarity shine).
* Introduce your product as a natural “next step.”

**Best angles:**

* Comparisons (“3 ways to solve X—here’s when each works”)
* Myth-busting (“Most people pick the wrong solution because…”)

**Best CTA:** “see how it works,” demo, case study, “choose the right option” guide.

---

## 4) Product-Aware

**Mindset:** They know your product exists, but they’re **not fully convinced** it’s the best fit / best performer / best value. ([ActiveCampaign][1])

Schwartz (as commonly quoted): they aren’t completely aware of all it does, aren’t convinced how well it does it, or haven’t been told how much better it does it now. ([GrowthMarketer][5])

**What they’re thinking:**

* “Will this work for *my* situation?”
* “Is it better than the alternatives?”
* “What’s the catch—price, time, risk?”

**Your job in the script:**

* **Differentiate** (why you vs. the category vs. competitors).
* **Handle objections** (risk reversal, setup time, learning curve, reliability).
* Prove performance: testimonials, before/after, numbers, comparisons, demos.

**Best angles:**

* “Why we built it differently”
* “What changed (new feature, new guarantee, new proof)”
* Competitive comparisons / “vs” pages

**Best CTA:** free trial, live demo, consult, “see pricing,” “start in 2 minutes.”

---

## 5) Most-Aware

**Mindset:** They know your product, know they want it… they just need a nudge, a reason *now*, or clear next steps. ([ActiveCampaign][1])

Schwartz (as quoted): “The customer knows of your product—knows what it does—knows he wants it… just hasn’t gotten around to buying it yet.” ([GrowthMarketer][5])

**What they’re thinking:**

* “Remind me / make it easy.”
* “Is there a deal?”
* “What exactly do I get and how fast?”

**Your job in the script:**

* **Make the offer irresistible and frictionless**.
* Add urgency/scarcity ethically (deadline, bonus, limited slots).
* Tight CTA: “Buy / Start / Upgrade.”

**Best angles:**

* Limited-time bonus, guarantee, “start today”
* Retargeting reminder ads (“Still thinking about X?”)

**Best CTA:** direct purchase or checkout.

Recommended mechanics:

Token bucket per (platform, account, endpoint)

Retries/backoff
Exponential backoff with jitter

Max retry count per job type

Dead-letter queue: dlq.*

Token refresh strategy
Every adapter must expose:

getAuthState() (valid/expiring/invalid)

refreshAuth() (if possible)

The orchestrator runs a heartbeat:

if token expiring soon → refresh and store

if refresh fails → disable adapter + alert

“Adapter registry” pattern
// adapter-registry.ts
import type { Platform, PlatformAdapter } from "./platform-adapter";

export class AdapterRegistry {
  private adapters = new Map<Platform, PlatformAdapter>();

  register(adapter: PlatformAdapter) {
    this.adapters.set(adapter.platform, adapter);
  }

  get(platform: Platform): PlatformAdapter {
    const a = this.adapters.get(platform);
    if (!a) throw new Error(`No adapter registered for platform=${platform}`);
    return a;
  }
}

// publisher-worker.ts
import type { AdapterRegistry } from "./adapter-registry";
import type { DraftPublishPayload, JobEnvelope } from "./jobs";

export async function handleDraftPublish(
  registry: AdapterRegistry,
  job: JobEnvelope<DraftPublishPayload>,
  deps: {
    loadDraft: (draft_id: string) => Promise<{ text: string; channel: string; platform: string; reply_to?: string; dm_to?: string; parent_comment_id?: string; }>;
    markTouchpointPublished: (args: { draft_id: string; platform_object_id: string; platform_url?: string; published_at: string; }) => Promise<void>;
  }
) {
  const draft = await deps.loadDraft(job.payload.draft_id);
  const adapter = registry.get(draft.platform as any);

  // Rate limit guard (prefer centralized limiter in real implementation)
  const rl = await adapter.getRateLimitInfo();
  if (rl?.retry_after_ms) {
    throw new Error(`Rate limited: retry_after_ms=${rl.retry_after_ms}`);
  }

  let result;
  if (draft.channel === "post") {
    result = await adapter.publishPost({ text: draft.text, reply_to_platform_object_id: draft.reply_to });
  } else if (draft.channel === "comment") {
    if (!draft.parent_comment_id) throw new Error("Missing parent_comment_id");
    result = await adapter.replyToComment({ parent_comment_id: draft.parent_comment_id, text: draft.text });
  } else if (draft.channel === "dm") {
    if (!draft.dm_to) throw new Error("Missing dm_to");
    result = await adapter.sendDM({ recipient_handle: draft.dm_to, text: draft.text });
  } else {
    throw new Error(`Unsupported channel=${draft.channel}`);
  }

  await deps.markTouchpointPublished({
    draft_id: job.payload.draft_id,
    platform_object_id: result.platform_object_id,
    platform_url: result.platform_url,
    published_at: result.published_at
  });
}
